# Curso Spring Boot Expert: JPA, REST, JWT, OAuth2 com Docker e AWS 🚀

Este repositório contém todos os códigos, anotações e projetos práticos desenvolvidos ao longo do curso **"Spring Boot Expert"**, ministrado por Dougllas Sousa. O objetivo deste repositório é documentar a minha jornada de profissionalização em Java e Spring Boot, abordando desde a criação de projetos do zero até o deploy na nuvem da AWS.

## 📚 Sobre o Curso

O curso é um guia completo focado no desenvolvimento e manutenção de projetos Spring Boot, independentemente do seu tamanho. Ele explora a fundo a arquitetura do ecossistema Spring, preparando o aluno para criar aplicações modernas, seguras e escaláveis prontas para o mercado de trabalho.

## 🎯 Competências e Tópicos Abordados

Durante as aulas, os seguintes conhecimentos são aprofundados e colocados em prática:

*   **Arquitetura e Fundamentos:** Compreensão detalhada de como funciona toda a arquitetura do ecossistema Spring.
*   **APIs RESTful:** Modelagem e desenvolvimento de APIs utilizando conceitos e recursos avançados.
*   **Persistência de Dados (JPA):** Domínio de toda a base JPA (Java Persistence API) para o trabalho robusto com bancos de dados relacionais.
*   **Segurança (Spring Security e OAuth2):** Aplicação de segurança em APIs, criação de um serviço próprio de autenticação e autorização com OAuth2, e implementação de Login Social (com Google e outros provedores).
*   **Qualidade e Testes:** Criação e execução de Testes Unitários e de Integração.
*   **Documentação:** Documentação padronizada de APIs utilizando Swagger e Open API.
*   **DevOps e Containers (Docker):** Domínio da base do Docker para a construção de imagens e execução de serviços em containers.
*   **Cloud Computing (AWS):**
    *   Configuração e deploy de bancos de dados utilizando o serviço AWS RDS.
    *   Realização do deploy completo da aplicação Spring Boot na nuvem da AWS.

## 🛠️ Tecnologias e Ferramentas Utilizadas

*   **Linguagem:** Java (JDK 21)
*   **Framework Principal:** Spring Boot (Spring Web, Spring Data JPA, Spring Security)
*   **Banco de Dados:** H2 Database / PostgreSQL / MySQL
*   **Autenticação:** JWT, OAuth2
*   **Documentação:** Swagger / OpenAPI
*   **Infraestrutura:** Docker, AWS (RDS, EC2, etc.)
*   **Gerenciador de Dependências:** Maven
*   **IDE:** IntelliJ IDEA / VS Code / Eclipse
